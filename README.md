# blake3-kmp

Kotlin Multiplatform bindings for BLAKE3, with a JVM Foreign Function & Memory API (FFM) alternative.

## Published modules

Both artifacts use the group `com.akhsaul.blake3` and are published to GitHub Packages at `https://maven.pkg.github.com/akhsaul/blake3-kmp`.

| Module | Gradle coordinate | Platforms |
| --- | --- | --- |
| `blake3-kmp` | `com.akhsaul.blake3:blake3-kmp:<version>` | Kotlin Multiplatform: Android and JVM |
| `blake3-ffm` | `com.akhsaul.blake3:blake3-ffm:<version>` | JVM 22+ (Foreign Function & Memory API) |

Use a release tag without its `v` prefix as the version: tag `v0.4.1` publishes version `0.4.1`. The default local version is `0.1.0-SNAPSHOT`.

## Consume with Gradle

Add the GitHub Packages repository to dependency resolution, for example in `settings.gradle.kts`:

```kotlin
dependencyResolutionManagement {
    repositories {
        maven {
            url = uri("https://maven.pkg.github.com/akhsaul/blake3-kmp")
            credentials {
                username = providers.gradleProperty("gpr.user").orNull
                    ?: System.getenv("GITHUB_ACTOR")
                password = providers.gradleProperty("gpr.key").orNull
                    ?: System.getenv("GITHUB_TOKEN")
            }
        }
        mavenCentral()
    }
}
```

Add the desired artifact in the consumer's `build.gradle.kts`:

```kotlin
dependencies {
    implementation("com.akhsaul.blake3:blake3-kmp:<version>")
    // JVM 22+ alternative: implementation("com.akhsaul.blake3:blake3-ffm:<version>")
}
```

GitHub Packages requires credentials to download packages. For local builds, set `gpr.user` and `gpr.key` in `~/.gradle/gradle.properties`, or provide `GITHUB_ACTOR` and `GITHUB_TOKEN` as environment variables. A personal access token (classic) for package consumption needs the `read:packages` scope; do not commit it. In GitHub Actions, a consumer's `GITHUB_TOKEN` can read the package if that repository has package access. See [GitHub's Gradle registry authentication guide](https://docs.github.com/en/packages/working-with-a-github-packages-registry/working-with-the-gradle-registry#authenticating-to-github-packages).

## Local build and publication

`./gradlew publishToMavenLocal` publishes without GitHub credentials. A full Android publication requires an Android SDK; native libraries are generated by `VERSION=0.4.1-SNAPSHOT ./build-package` (requires Zig and `ANDROID_NDK_HOME`). Override the local version with `-Pversion=0.4.1-SNAPSHOT` when publishing directly with Gradle.

For formatting and static checks that do not run native-dependent tests, use:

```sh
./gradlew spotlessCheck check -x testAndroid -x testAndroidHostTest -x jvmTest -x androidConnectedCheck -x test
```

The `.github/workflows/build-publish.yaml` workflow tests the project before publishing both modules to GitHub Packages on `v*` tags. It uses the workflow's `GITHUB_TOKEN` with `packages: write` permission.
